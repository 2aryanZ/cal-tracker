# Cal Tracker v1.1.5

This release brings the Tempo journal design to all four main tabs, improves first-run setup and repeat meal logging, and makes logged nutrition summaries easier to interpret.

## What's new

- Find recent meals and favorites at the top of the meal picker. Search, filter and review a saved meal before logging it again.
- Set up a personal profile through three short steps with blank first-use measurements, input checks and a review of the calculated plan.
- See average calories and target adherence based on days with recorded meals, with logging coverage shown separately. Missing days are not displayed as zero intake.
- Improve readability of weight and nutrition metrics on Android phones with different system text sizes.
- Refine the Tempo Today, History, Progress and Profile screens.

## Android download

`cal-tracker-v1.1.5-android.apk` is the signed production APK for direct installation from this GitHub release. Android version code: 9. This APK is for direct Android installation; Google Play accepts an Android App Bundle (AAB) for store submission.
